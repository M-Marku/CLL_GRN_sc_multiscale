# Integrating drug pharmacokinetics with single-cell gene regulatory networks reveals a predominantly intrinsic transcriptional programme of ibrutinib resistance in CLL

**Malvina Marku, Cécile Pineau, Marcelo Hurtado, Hugo Chenel, Vera Pancaldi, Jean-Baptiste Woillard, Loïc Ysebaert, Étienne Chatelut, Melanie White-Koning**

*Centre de Recherches en Cancérologie de Toulouse (CRCT) | Institut Universitaire du Cancer de Toulouse Oncopole*

---

## Overview

This repository contains all code, model files, and processed results to reproduce the analyses in the paper. The study integrates four computational layers to dissect the mechanisms of ibrutinib resistance in a single CLL patient with longitudinal CITE-seq data (Cadot et al., 2020):

1. **Gene regulatory network (GRN) inference** — pySCENIC applied to single-cell CLL transcriptomes at M0, M3, and M27
2. **Trajectory inference** — CellRank fate probability analysis and Slingshot pseudotime
3. **Clonal phylogenetics** — CopyKAT CNV inference, subclone identification, neighbour-joining tree, ancestral state reconstruction
4. **PK-Boolean coupled model** — stochastic MaBoSS Boolean network of CLL BCR/BTK signalling, initialised from AUCell transcriptomic states and coupled to patient-specific ibrutinib pharmacokinetic profiles
5. **PK-transcriptomic integration** — AutoML regression and Spearman correlation to dissect intrinsic vs acquired resistance at the gene and TF regulon level

The central finding is that ibrutinib resistance in this patient is predominantly intrinsically determined: a resistant subclone (Clone_3) carrying a JUN/AP-1-active, BCR-desensitised transcriptional programme was already present before treatment and expanded under constant drug pressure, rather than emerging de novo under pharmacological selection.

## Data

### CITE-seq data (Cadot et al. 2020)

The single-cell CITE-seq dataset used in this study is from:

> Cadot S, Valle C, Tosolini M, et al. (2020). Longitudinal CITE-Seq profiling of chronic lymphocytic leukemia during ibrutinib treatment. *Biomarker Research*, 8(1):72. https://doi.org/10.1186/s40364-020-00253-w

The processed data (Seurat object) can be obtained from the authors of the original study. We used the CLL/B-cell subpopulation only (10,570 cells × 33,694 genes). Place the Seurat object at:

```
data/seurat_cll_bcells.rds
```

### Pharmacokinetic data

Patient-specific ibrutinib PK data (individual concentration-time profiles and derived AUC metrics) are from the population PK model described in:

> Gallais F, Ysebaert L, Despas F, et al. (2021). Population PK-PD Modeling of Circulating Lymphocyte Dynamics in CLL Patients Under Ibrutinib Treatment. *Clinical Pharmacology & Therapeutics*, 110(1):220–228. https://doi.org/10.1002/cpt.2189

These data are patient-level clinical data and are not publicly shareable. Researchers wishing to reproduce the PK-coupled Boolean analysis should contact the corresponding author (malvina.marku@inserm.fr) to discuss data access.

### Reference files for pySCENIC

Download from https://resources.aertslab.org/cistarget/ and place in `data/scenic_references/`:

```bash
# Databases
wget https://resources.aertslab.org/cistarget/databases/homo_sapiens/hg19/refseq_r45/mc9nr/gene_based/hg19-500bp-upstream-7species.mc9nr.feather
wget https://resources.aertslab.org/cistarget/databases/homo_sapiens/hg19/refseq_r45/mc9nr/gene_based/hg19-tss-centered-5kb-7species.mc9nr.feather

# Motif annotation
wget https://resources.aertslab.org/cistarget/motif2tf/motifs-v9-nr.hgnc-m0.001-o0.0.tbl

# Data/allTFs_hg38.txt
```

## Analysis pipeline

The analyses should be run in the following order, matching the Results section of the paper.

### Step 1 — Data preparation

```r
Rscript scripts/R/01_seurat_data_extraction.R
```

Extracts the CLL B-cell subpopulation from the full CITE-seq Seurat object. Outputs a filtered Seurat object and cell-timepoint annotation used throughout the pipeline.

**Input:** `data/seurat_cll_bcells.rds`
**Output:** `data/seurat_cll_filtered.rds`, `data/cell_time_annotation.csv`

---

### Step 2 — GRN inference with pySCENIC

```bash
jupyter nbconvert --to notebook --execute scripts/notebooks/01_GRN_pySCENIC.ipynb
```

Runs the full pySCENIC pipeline (GRNBoost2 → RcisTarget motif enrichment → AUCell scoring) on the CLL subpopulation. This step is computationally intensive and was run on the Genotoul bioinformatics cluster (https://bioinfo.genotoul.fr). Recommended: ≥32 cores, ≥64 GB RAM.

**Input:** Filtered Seurat expression matrix, SCENIC reference files
**Output:** `results/pyScenic_results/` — adjacency files, regulon objects, AUCell score matrices, GRN edge tables

---

### Step 3 — GRN analysis

```r
Rscript scripts/R/02_RSS_calculation.R          # Regulon Specificity Scores
Rscript scripts/R/03_centrality_measures.R      # Degree and betweenness centrality
Rscript scripts/R/04_RWR.R                      # Random walk with restart
Rscript scripts/R/05_infer_interaction_signs.R  # GRN edge sign inference
```

Characterises the GRN structure: identifies M27-specific TFs by RSS + Wilcoxon test, computes network centrality, propagates ibrutinib's inhibitory signal through the M0 GRN using random walk with restart seeded from DGIdb drug-gene interactions (`data/drug_interaction_ibrutinib.tsv`), and infers activation/inhibition signs for GRN edges.

**Input:** `results/pyScenic_results/`
**Output:** `results/pyScenic_results/sig_up_TFs_M27_RSS_Wilcoxon.csv`, GRN edge files with signs, centrality tables

---

### Step 4 — AUCell binarisation

```r
Rscript scripts/R/06_AUCell_binarisation.R
```

Binarises per-cell AUCell scores using per-regulon thresholds (valley of bimodal distribution if BC > 0.555, otherwise discriminability-maximising threshold) and aggregates to a majority-vote binary consensus per timepoint (M0/M3/M27). The binary consensus is used to initialise TF node states in the Boolean model.

**Input:** `results/pyScenic_results/AUcell_CLL_only.csv`
**Output:** `results/pyScenic_results/aucell_binary_consensus.csv`, `results/pyScenic_results/aucell_binary_matrix.csv`

---

### Step 5 — Trajectory inference

```bash
jupyter nbconvert --to notebook --execute scripts/notebooks/02_trajectory_CellRank.ipynb
```

```r
Rscript scripts/R/07_slingshot_trajectory.R     # Slingshot validation
Rscript scripts/R/08_corr_aucell_fateprob.R     # AUCell–fate probability correlation
```

Infers cell fate probabilities using CellRank (ConnectivityKernel + GPCCA). Identifies M3 and M27 as separate terminal macrostates. Validates with Slingshot and STREAM. Correlates AUCell regulon activity with fate probabilities to identify fate-specific TFs.

**Input:** Preprocessed AnnData object (Scanpy), `results/pyScenic_results/AUcell_CLL_only.csv`
**Output:** `results/CellRank_results/` — fate probability matrices, driver gene lists, figures

---

### Step 6 — Clonal phylogenetics

```r
Rscript scripts/R/09_clonal_phylogenetics.R
```

Infers CNV profiles from scRNA-seq using CopyKAT, identifies three tumour subclones by hierarchical clustering, reconstructs a neighbour-joining phylogenetic tree rooted with the diploid outgroup, performs ancestral state reconstruction (equal-rates model, phytools::fitMk), and characterises Clone_3 by differential expression.

**Input:** `data/seurat_cll_filtered.rds`
**Output:** Clone assignments, NJ tree, ancestral state reconstruction figures, DEG results

---

### Step 7 — PK profile and visualisation

```r
Rscript scripts/R/10_PK_profile.R
```

Processes patient-specific ibrutinib concentration data, computes monthly troughs (bottom 10th percentile), cumulative AUC (trapezoidal integration), and produces PK profile figures.

**Input:** Patient PK data (not shared — see Data section)
**Output:** `results/PK_results/` — processed PK tables, `results/PK_Boolean_results/monthly_pk_concentrations.csv`

---

### Step 8 — PK-Boolean coupled simulation

```bash
jupyter nbconvert --to notebook --execute scripts/notebooks/03_Boolean_PK_coupled.ipynb
```

The main modelling analysis. Couples patient-specific ibrutinib PK profiles with the CLL Boolean network (v6, 37 nodes) via:
- Hill equation conversion of monthly trough concentrations to BTK rate_up
- AUCell-derived binary TF states for model initialisation (M0/M3/M27)
- Logistic PLCG2_mutant clonal expansion model driven by cumulative AUC

Runs state-chained monthly MaBoSS simulations (M0→M27, 50 replicates), single-node perturbation screens (S1/S1b), cytokine rescue (S2), Bliss synergy screens (S3/S3b), basin of attraction mapping (S4), and BTK dose-response (S5). Also runs IC50 and AUC₅₀ sensitivity analyses.

**Requires:**
- `model/leukemia_hgnc_v4CLL_v6.bnd`
- `model/init_v6_base.cfg`
- `results/pyScenic_results/aucell_binary_consensus.csv`
- Patient PK data (not shared — see Data section)

**Output:** `results/PK_Boolean_results/` — attractor trajectory CSVs, perturbation screen results, sensitivity analysis results, all figures

---

### Step 9 — PK-transcriptomic integration

```r
Rscript scripts/R/11_automl_pk_integration.R   # AutoML regression (h2o)
Rscript scripts/R/12_grn_pk_correlation.R       # Spearman correlation
```

Tests whether ibrutinib pharmacokinetic exposure predicts transcriptomic variation using two approaches:

**AutoML regression (h2o):** Predicts M0-residualised gene expression and TF regulon activity at M3 and M27 from PK features. Run separately for three PK metrics (cumulative AUROC, per-interval AUROC, instantaneous concentration); results stored in `results/ML_results/h2o_automl_cumulAUROC/` (primary), `h2o_automl_AUROC/`, and `h2o_automl_conc/`.

**Spearman correlation:** Correlates individual gene expression trajectories with cumulative AUROC to identify PK-driven activated and suppressed gene signatures.

**Input:** Pseudo-bulk expression from Seurat, AUCell scores, PK data
**Output:** `results/ML_results/` — R² metrics, gene/TF classification, figures

## Boolean network model

The CLL Boolean network (v6) was adapted from the Bio Model Analyser CML leukaemia signalling network (Chuang et al. 2015, *Scientific Reports*) and reengineered for CLL biology. Key modifications:

| Feature | Description |
|---|---|
| Nodes | 37 (reduced from 52 in v5 by removing 15 non-CLL nodes) |
| Edges | 66 (52 activation, 14 inhibition) |
| Central kinase | BTK (replaces BCR-ABL1 from CML model) |
| Resistance mechanism | PLCG2_mutant gain-of-function (ibrutinib bypass) |
| Output nodes | Apoptosis, Proliferation, Growth_Arrest, Resistance |
| BTK inhibition | Continuous Hill equation rate (not binary lock) |
| Initialisation | AUCell binary consensus TF states per timepoint |

The model files are in MaBoSS format and can be opened with:
- **MaBoSS** (simulation): https://maboss.curie.fr
- **pyMaBoSS** (Python API): `pip install pymaboss`
- **yEd** (GraphML visualisation): https://www.yworks.com/products/yed

Full model description including all Boolean rules is in Supplementary Material 1 of the paper.
